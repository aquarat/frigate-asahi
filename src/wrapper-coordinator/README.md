# wrapper-coordinator (not included)

The Mac deployment's ffmpeg TCP proxy (a drop-in `ffmpeg`/`ffprobe` wrapper inside the
container plus a native coordinator daemon on the macOS host). It is not used by the Linux
deployment in this repository and is kept here only as a pointer: the source lives in the
separate `frigate-remote-ffmpeg` repository on the same GitHub account. `src/mac-originals/STACK_GUIDE.md`
describes how it was used on the Mac.
